# 🎬 Preparación de Demo para Presentación

## ¿Qué es la "Demo"?

La demo NO es código nuevo - Streamlit YA ES la demo funcionando.

La "preparación de demo" significa tener **casos de uso listos** para mostrar en la presentación, para que sea fluida y profesional.

## 📋 Casos de Uso Preparados

### Caso 1: Blog Post con Perfil Personalizado
**Input:**
- Topic: "Inteligencia Artificial en educación"
- Platform: Blog Post
- Audience: Educadores y administradores escolares
- Tone: Informativo
- Language: Spanish
- Perfil: "TechEdu", "Educación Tecnológica", "Innovador y accesible"

**Resultado esperado:** Blog post profesional con tono personalizado

## 🎯 Para la Presentación

1. **Abrir la app** → http://localhost:8501
2. **Mostrar sidebar** → Selector de LLM, Perfil personalizado
3. **Generar contenido** → Usar uno de los casos preparados
4. **Mostrar resultado** → Contenido + imagen (si está configurado)
5. **Cambiar idioma** → Generar mismo contenido en otro idioma
6. **Cambiar LLM** → Mostrar que se puede elegir provider

## ⏱️ Tiempo de Demo

- **5-7 minutos** es suficiente para mostrar:
  - Configuración (1 min)
  - Generación de contenido (2 min)
  - Multiidioma (1 min)
  - Imágenes (1 min)
  - Diferentes plataformas (2 min)

## 💡 Tips

- Ten la app corriendo ANTES de la presentación
- Ten los casos de uso escritos en un papel/archivo
- Prueba cada caso ANTES de la presentación
- Si algo falla, ten un caso de respaldo
